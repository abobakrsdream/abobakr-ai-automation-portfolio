# Abobakr — AI Automation Engineer Portfolio

A responsive, animated portfolio built with React, Vite, TypeScript, Tailwind CSS, Motion, and lucide-react.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Customize

- Edit project descriptions and statuses in `src/App.tsx`.
- Update contact details in the `phone` and `email` constants in `src/App.tsx`.
- Adjust colors and typography in `src/styles.css`.
- The current contact actions use `mailto:` and WhatsApp deep links. No backend form submission is configured.

## Notes

Project statuses are intentionally labelled as in development or concept where completion has not been confirmed. No fabricated testimonials, client metrics, GitHub statistics, or years of experience are included.
